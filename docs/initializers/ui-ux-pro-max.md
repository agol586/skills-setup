# UI UX Pro Max initializer

Source: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Official references: [installation and usage](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill#installation) and [search script](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/scripts/search.py).

The installer runs `ui-ux-pro-max-cli` through `npx` in a temporary staging directory with `uipro init --ai <agent> --offline`. The `--ai` keys are `codex`, `claude`, and `cursor`. This produces the primary `ui-ux-pro-max` skill and its companion design skills. Before target writes, the installer matches each existing companion to the staged source by exact content or its upstream `name` and `author` identity, so an older bundled version can remain in place while an unrelated same-name skill stops the run. It checks every staged file's target path for links outside the project, copies only missing files, and preserves existing instructions. The setup workflow then normalizes invocation metadata for model selection. It checks that every bundled skill and the primary Python search script exist, then runs a small UX search as a smoke check. Restart the agent so the new skills are discoverable.

Read the target README, design docs, tokens, component library, and stack documentation before using the skill to recommend a design system. If the project already has an approved design system, use it as the baseline and query the skill for specific gaps; keep existing tokens and brand rules authoritative. If no design guidance exists, record where a design system would live and generate one when actual UI work begins. The upstream search script supports `--design-system`; `--persist` writes a `design-system/` tree, so use persistence only when that matches the project's documentation layout and the generated system has been reviewed. A separate `--stack` query can add framework-specific guidance.

When Taste Skill is also selected, point both skills at the same project design documentation. Use UI UX Pro Max for references and recommendations, and Taste Skill for judging the final layout, typography, motion, and density; reconcile any differing suggestion against the project's established design rules.

Check: every bundled skill, including the primary `ui-ux-pro-max` skill and `scripts/search.py`, is present; the search smoke check succeeds; the agent can discover the skills after restart; and the project docs clearly identify the authoritative design guidance.
